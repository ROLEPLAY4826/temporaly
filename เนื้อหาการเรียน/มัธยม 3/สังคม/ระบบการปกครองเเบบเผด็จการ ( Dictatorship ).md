ระบบการปกครองเเบบเผด็จการ ( Dictatorship )
	ความหมายของระบบการปกครองเผด็จการ ( Meaning of Dictatorship ):
		คือ: การปกครองที่อำนาจสูงสุดอยู่ในมือบุคคลหนึ่งคนหรือคณะบุคคลกลุ่มเล็ก ๆ
	จุดเด่น: 
		- รวมศูนย์อำนาจ
		- จำกัดการมีส่วนร่วมของประชาชน
		- จำกัดสิทธิเสรีภาพบางประการ
		- เน้นความรวดเร็วในการตัดสินใจ
	รูปเเบบการใช้อำนาจเเบ่งเป็น 3 เเบบ: 
		คือ: แบ่งตามว่าใครเป็นผู้ถืออำนาจสูงสุด
		เเบ่งเป็น:
			/1/. เผด็จการทหาร
			/2/. เผด็จการพรรคการเมือง
			/3/. เผด็จการบุคคล
-
			/1/. ผู้มีอำนาจสูงสุด
					คณะทหาร
			/2/. ผู้มีอำนาจสูงสุด
					พรรคการเมือง
			/3/. ผู้มีอำนาจสูงสุด
					ผู้นำคนเดียว

![[Pasted image 20260616220958.png]]

เเบ่งเป็น 3 รูปเเบบ:
	/1/. เผด็จการเเบบอำนาจนิยม
	/2/. เผด็จการเเบบเบ็ดเสร็จ
		/2.1/. ระบบเผด็จการฟาสซิลต์
		/2.2/. ระบบเผด็จการคอมมิวนิสต์
		/2.3/. ระบบเผด็จการเเบบอำนาจนิยม ( Totalitarian Dictatorship )

	/1/.
