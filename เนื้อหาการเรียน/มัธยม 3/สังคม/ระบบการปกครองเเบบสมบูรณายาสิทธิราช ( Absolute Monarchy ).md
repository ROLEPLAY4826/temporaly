ระบบการปกครองเเบบสมบูรณายาสิทธิราช ( Absolute Monarchy )
	ความหมายของระบบการปกครองเเบบสมบูรณายาสิทธิราช ( Meaning of Absolute Monarchy )
		คือ: ระบอบการปกครองที่พระมหากษัตริย์ทรงมีอำนาจสูงสุดในการบริหารประเทศ การออก
		    กฎหมาย และการตัดสินคดีความ โดยอำนาจทั้งหมดรวมอยู่ที่องค์พระมหากษัตริย์
	จุดเด่น:
		1. **พระมหากษัตริย์ทรงมีอำนาจสูงสุด**
			- ทรงเป็นทั้งประมุขของรัฐและผู้ใช้อำนาจในการปกครอง
		2. **อำนาจไม่ถูกจำกัดโดยรัฐธรรมนูญ**
			- ไม่มีรัฐธรรมนูญหรือสถาบันทางการเมืองที่สามารถควบคุมอำนาจของพระมหากษัตริย์ได้
		3. **ประชาชนไม่มีส่วนร่วมในการปกครองโดยตรง**
			- ไม่มีการเลือกตั้งผู้ปกครองจากประชาชน หรือมีบทบาทจำกัดมาก
		4. **การตัดสินใจเป็นไปอย่างรวดเร็ว**
			- เนื่องจากอำนาจรวมศูนย์อยู่ที่ผู้ปกครองเพียงผู้เดียว

ข้อดี:
	- การบริหารประเทศมีความรวดเร็วและเป็นเอกภาพ
	- สามารถตัดสินใจแก้ปัญหาต่าง ๆ ได้ทันที
	- ลดความขัดแย้งทางการเมืองจากการแข่งขันของพรรคการเมือง
ข้อเสีย:
	- อาจเกิดการใช้อำนาจโดยมิชอบหากผู้ปกครองขาดคุณธรรม
	- ประชาชนมีสิทธิและเสรีภาพทางการเมืองจำกัด
	- ขาดการตรวจสอบและถ่วงดุลอำนาจ
