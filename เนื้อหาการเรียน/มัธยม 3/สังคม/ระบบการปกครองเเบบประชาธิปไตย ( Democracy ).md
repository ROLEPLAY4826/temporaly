ระบบการปกครองเเบบประชาธิปไตย ( Democracy )
	ความหมายของระบบการปกครองเเบบประชาธิปไตย
		คือ: การปกครองที่ประชาชนเป็นเจ้าของอำนาจอธิปไตย
	ความโดดเด่น:
		คือ:   - ประชาชนมีส่วนร่วมทางการเมือง
			- มีการเลือกตั้งที่เสรีและเป็นธรรม
			- เคารพสิทธิ เสรีภาพ และความเสมอภาค
			- มีการตรวจสอบและถ่วงดุลอำนาจ
	รูปเเบบการใช้อำนาจ: 
		คือ: วิธีที่ประชาชนใช้อำนาจอธิปไตยในการปกครองประเทศ ( ในระบอบประชาธิปไตย อำนาจ
			อธิปไตยเป็นของประชาชน แต่ประชาชนสามารถใช้อำนาจนั้นได้หลายรูปแบบ )
		ได้เเก่: 1. ประชาธิปไตยทางตรง      ( Direct Democracy )
			   2. ประชาธิปไตยทางอ้อม     ( Indirect Democracy หรือ Representative Democracy )
			   3.  ประชาธิปไตยทางอ้อม    ( Semi-Direct Democracy หรือ
								    Semi-Representative Democracy )
	*** อำนาจอธิปไตย 
		 - เป็นของประชาชน
		 - ใช้ผ่านฝ่ายนิติบัญญัติ ฝ่ายบริหาร และ ฝ่ายตุลาการ

ประชาธิปไตยเเบ่งออกเป็น 3 ประเภท:
	/1/. ระบอบประชาธิปไตยเเบบรัฐสภา ( Parliamentary System )
	/2/. ระบอบประชาธิปไตยเเบบประธานาธิบดี ( Presidential System )
	/3/. ระบอบประชาธิปไตยเเบบกึ่งรัฐบาลกึ่งประธานาธิบดี ( Semi-Presidential System )
-
	/1/. การใช้อำนาจ:
			- ประชาชนเลือกสมาชิกสภาผู้แทนราษฎร
			- รัฐสภาเป็นศูนย์กลางทางการเมือง
			- นายกรัฐมนตรีมาจากเสียงข้างมากในรัฐสภา
		ประมุขของชาติ ( Head of state ):
			พระมหากษัตริย์เป็นประมุข เเละ ประธานาธิบดีเป็นประมุข
			
![[Pasted image 20260616231129.png]]
	/2/. การใช้อำนาจ:
			- ประชาชนเลือกประธานาธิบดี
			- ประธานาธิบดีเป็นทั้งประมุขและหัวหน้าฝ่ายบริหาร
			- แยกอำนาจจากรัฐสภาค่อนข้างชัดเจน
		ประมุขของชาติ ( Head of state ):
			ประธานาธิบดีเป็นประมุข
			
![[Pasted image 20260616220716.png]]
	/3/. การใช้อำนาจ:
			- มีประธานาธิบดีและนายกรัฐมนตรี
			- ประธานาธิบดีดูแลบางเรื่อง เช่น ความมั่นคงหรือนโยบายต่างประเทศ
			- นายกรัฐมนตรีบริหารงานรัฐบาลประจำวัน
		ประมุขของชาติ ( Head of state ):
			ประธานาธิบดีเป็นประมุข

เเบ่งออกอีกเป็น 2 ระบบ:
	1. **ระบอบราชาธิปไตยภายใต้รัฐธรรมนูญ (Constitutional Monarchy)**
		- มีกษัตริย์เป็นประมุขของรัฐ
		- การปกครองเป็นไปตามรัฐธรรมนูญ และมีรัฐบาลบริหารประเทศ
	2. **สาธารณรัฐประชาธิปไตย (Democratic Republic)**
		- ไม่มีพระมหากษัตริย์เป็นประมุข
		- มี **ประธานาธิบดี** เป็นประมุขของรัฐ
		- ประชาชนเลือกตั้งผู้แทนหรือประธานาธิบดีตามระบบของแต่ละประเทศ
