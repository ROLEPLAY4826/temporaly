พีชคณิต ( Algebra ):
	ความหมายของพีชคณิต ( Meaning of algebra ):
		พีชคณิต คือ สาขาหนึ่งในวิชาคณิตศาสตร์ ที่มีสัญลักษณ์เเละตัวเเปรเเทนตัวเลขที่ยังไม่ทราบค่า
				   ให้ศึกษาเเละหาความสัมพันธ์ของจำนวนเหล่านั้น
			ประกอบด้วย:
				1.  ตัวเเปร ( Variables ):
					ความหมาย: สัญลักษณ์หรือตัวอักษรที่เเทนถึง ตัวเลขที่ยังไม่ทราบ
				2.  ค่าคงที่ ( Constants ):
					ความหมาย: ตัวเลขที่มีค่าเป็นอย่างนั้นเสมอ
				3.  นิพจน์พีชคณิต ( Algebraic Expressions ):
					ความหมาย: กลุ่มตัวเลขเเละตัวเเปรที่ทำกระบวนการทางคณิตศาสตร์กัน
							  ประกอบด้วยพจน์ตั้งแต่ 1 พจน์ขึ้นไป
				4.  พหุนาม ( Polynomials ):
					ความหมาย: นิพจน์พีชคณิตที่มีหลายพจน์
						เเบ่งเป็น:
							1. เอกนาม ( Monomials ):
								หมายถึง: นิพจน์ 1 พจน์
							2. ทวินาม ( Binomials ):
								หมายถึง: นิพจน์ 2 พจน์
							3. ตรีนาม ( Trinomials ):
								หมายถึง: นิพจน์ 3 พจน์
								        ...
				5.  สมการ ( Equations ):
					ความหมาย: การเท่ากัน ( = ) ของกลุ่มตัวเลข 2 กลุ่ม
				6.  อสมการ ( Inequalities ):
					ความหมาย: การไม่เท่ากัน ( >, <, ≠, ≥, ≤ ) ของกลุ่มตัวเลข 2 กลุ่ม
				7.  ฟังก์ชั่น ( Functions ):
					ความหมาย: ความสัมพันธ์ระหว่างค่าที่ป้อนเข้ากับผลลัพท์ที่ได้
					
พหุนาม ( Polynomials ):
	ความหมายของพหุนาม ( Meaning of polynomials ):
		คือ: นิพจน์ที่มีตั้งเเต่ 2 พจน์ขึ้นไป
			ประกอบด้วย:
				1. พจน์ ( Terms ):
					ความหมาย: กลุ่มตัวเลขหรือเเละตัวเเปรที่มีเครื่องหมาย + หรือ -
				2. สัมประสิทธิ์ ( Coefficients ):
					ความหมาย: ตัวเลขที่คูณอยู่กับตัวเเปร
				3. ตัวเเปร ( Variables ):
					ความหมาย: สัญลักษณ์หรือตัวอักษรที่เเทนตัวเลขที่ไม่ทราบค่า
				4. เลขชี้กำลัง ( Exponentials ):
					ความหมาย: ตัวเลขที่เเสดงจำนวนครั้งที่เลขฐานต้องคูณกันตามจำนวนครั้งนั้น
				5. พจน์ที่เป็นค่าคงที่ ( Constant Terms ):
					ความหมาย: พจน์ที่มีเพียงค่าคงที่เพียงอย่างเดียว

การบวนการทางพหุนาม ( Polynomial Operations ):
	ความหมายของกระบวนการทางพีชคณิต ( Meaning of Polynomial Operations ):
		คือ: การการคำนวณของพหุนาม
			ประกอบด้วย:
				1. การบวกกันของพหุนาม ( Addition of polynomials ):
					หมายถึง: การนำพหุพจน์มาบวกกัน
				2. การลบกันของพหุนาม ( Subtraction of polynomials ):
					หมายถึง: การนำพหุพจน์มาลบกัน
				3. การคูณกันของพหุนาม ( Multiplication of polynomials ):
					หมายถึง: การนำพหุพจน์มาคูณกัน
				4. การหารพหุนาม ( Division of polynomials ):
					หมายถึง: การหารพหุพจน์ด้วยพหุนามหรือเอกนาม

เอกลักษณ์ทางพีชคณิต ( Algebraic Identities ):
	ความหมายของเอกลักษณ์ทางพีชคณิต ( Meaning of Polynomials Identities ):
		คือ: สูตรที่มีความเกี่ยวข้องกับพีชคณิตเเละจะเป็นจริงเสมอไม่ว่าตัวเเปรจะเป็นค่าใด
			สูตร ได้เเก่:
				1. กำลังสองสัมบูรณ์ของผลบวก หรือ กำลังสองของทวินาม 
				   ( Perfect squared of the sum || Squared of Binomial ):
					    หมายถึง: ชื่อของสูตรที่่เเสดงความสัมพันธ์ของกำลังสองของทวินามกับ
						        ผลลัพท์ (บวก)
						สูตร: (x + y)² = x² + 2xy + y²
				2. กำลังสองสัมบูรณ์ของผลลบ หรือ กำลังสองของทวินาม 
				   ( Perfect squared of the difference || Squared of Binomial ):
					    หมายถึง: ชื่อของสูตรที่่เเสดงความสัมพันธ์ของกำลังสองของทวินามกับ
						        ผลลัพท์ (ลบ)
						สูตร: (x - y)² = x² - 2xy + y²
				3. ผลต่างกำลังสอง ( Difference of the squared ):
					    หมายถึง: ชื่อของสูตรที่่เเสดงความสำพันธ์ของผลต่างกำลังสองกับผลลัพท์ 
						สูตร: x² - y² = (x + y)(x - y)
				4. กำลังสามสัมบูรณ์ของผลบวก ( Perfect cubed of sum ):
					    หมายถึง: ชื่อของสูตรที่่เเสดงความสัมพันธ์ของกำลังสามของทวินามกับ
						        ผลลัพท์ (บวก)
						สูตร: (x + y)³ = x³ + 3x²y + 3xy² + y³
				5. กำลังสามสัมบูรณ์ของผลลบ ( Perfect cubed of difference ):
					    หมายถึง: ชื่อของสูตรที่่เเสดงความสัมพันธ์ของกำลังสามของทวินามกับ
						        ผลลัพท์ (ลบ)
						สูตร: (x - y)³ = x³ - 3x²y + 3xy² - y³
				6. ผลบวกกำลังสาม ( Sum of cubed ):
					    หมายถึง: ชื่อของสูตรที่่เเสดงความสัมพันธ์ของผลบวกกำลังสามกับผลลัพท์
					            (บวก)
						สูตร: x³ + y³ = (x + y)(x² - xy + y²)
				7. ผลต่างกำลังสาม ( Difference of cubed ):
					    หมายถึง: ชื่อของสูตรที่่เเสดงความสัมพันธ์ของผลต่างกำลังสามกับผลลัพท์
					            (บวก)
						สูตร: x³ - y³ = (x - y)(x² + xy + y²)
				8. กำลังสองสัมบูรณ์ของพจน์ 3 ตัว หรือ กำลังสองของตรีนาม 
				   ( Perfect squared of the 3 terms || Squared of ธพรnomial ):
					    หมายถึง: ชื่อของสูตรที่่เเสดงความสัมพันธ์ของกำลังสองของตรีนามกับ
						        ผลลัพท์ (บวก)
						สูตร: (a + b + c)² = a² + b² + c² + 2ab + 2ac + 2bc
				9. เอกลักษณ์พื้นฐานอีกแบบ
				   ( Another identity ):
					    หมายถึง: ชื่อของสูตรที่่เเสดงความสัมพันธ์ของกำลังสองของตรีนามกับ
						        ผลลัพท์ (บวก)
						สูตร: (a + b + c)² = a² + b² + c² + 2ab + 2ac + 2bc
				10. ผลบวกของกำลังสองของผลบวกและผลต่าง
				   ( Sum of perfect squared of sum and perfect squared of difference):
					    หมายถึง: ชื่อของสูตรที่่เเสดงความสัมพันธ์ของผลรวมของกำลังสองของ
							    ทวินามกับผลลัพท์ (บวกเเละลบ)
						สูตร: (a + b)² + (a - b)² = 2(a² + b²)
				11. ผลต่างของกำลังสองของผลบวกและผลต่าง
				   ( Difference of perfect squared of sum and perfect squared of difference):
					    หมายถึง: ชื่อของสูตรที่่เเสดงความสัมพันธ์ของผลต่างของกำลังสองของ
							    ทวินามกับผลลัพท์ (บวกเเละลบ)
						สูตร: (a + b)² - (a - b)² = 4ab
