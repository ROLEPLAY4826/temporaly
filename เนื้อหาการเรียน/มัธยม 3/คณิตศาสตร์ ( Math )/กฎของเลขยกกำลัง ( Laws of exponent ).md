เลขชี้กำลัง ( Exponent ):
	ความหมาย: กลุ่มตัวเลขที่มีเลขฐานเเละเลขตัวเล็กที่อยู่บนขวาของเลขฐาน
	 ประกอบด้วย:
	 1. การยกกำลังด้วยศูนย์ ( Zero exponent ):
		 มีกฎว่า: จำนวนใดๆที่ไม่ใช่ศูนย์ หากมีศูนย์เป็นเลขชี้กำลัง เเล้วจะได้ผลลัพท์เป็นหนึ่ง
		 สูตร: x^0 = 1 ; x ≠ 0
		 เช่น: 5^0 = 1
		 ข้อยกเว้น: 0^0 = ไม่มีนิยาม
	 2. การยกกำลังด้วยหนึ่ง ( One exponent ):
		 สูตร: x^1 = x
		 มีกฎว่า: จำนวนใดที่ยกกำลังด้วย 1 จะได้เลขตัวเดิมเสมอ
		 เช่น: 8^1 = 8 ; 999999^1 = 999999
	 3. การคูณของเลขยกกำลัง ( Multiplication of exponential expression ):
		 สูตร: (x^m) x (x^n) = x^(m+n)
		 มีกฎว่า: ผลคูณของเลขยกกำลังที่มีฐานเป็นตัวเลขเดียวกัน ให้เอาเลขชี้กำลังมาบวกกัน
		 เช่น: (8^3) x (8^13) = 8^(3 + 13) = 8^16 
	 4. การหารของเลขยกกำลัง ( Division of exponential expression ):
		 สูตร: (x^m) / (x^n) = x^(m-n)
		 มีกฎว่า: ผลหารของเลขยกกำลังที่มีฐานเป็นตัวเลขเดียวกัน ให้เอาเลขชี้กำลังมาลบกัน
		 เช่น: (8^3) / (8^13) = 8^(3 - 13) = 8^(-10 )
	 5. การยกกำลังเลขยกกำลัง ( Power of the exponential expression ):
		 สูตร: (x^m)^n = x^(m x n)
		 มีกฎว่า: เลขยกกำลังที่ถูกยกกำลังอีกทีหนึ่ง ให้เอาเลขชี้กำลังที่อยู่ในวงเล็บคูณกับ
		    เลขชี้กำลังของเลขยกกำลังทั้งหมด
		 เช่น: (5^4)^6 = 5^(4 x 6) = 5^24 = 59,604,644,775,390,625
	 6. การยกกำลังผลคูณ ( Power of a product ):
		 สูตร: (xy)^n = (x^n) x (y^n)
		 เช่น: ( 5 x 4 )^2 = (5^2) x (4^2) = 25 x 16 = 400
