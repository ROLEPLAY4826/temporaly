กรณฑ์ ( Radical ):
	 ความหมาย: เครื่องหมายกรณฑ์รวมดีกรีเเละเลขที่มีเครื่องหมายกรณฑ์ครอบอยู่
	 ประกอบด้วย: 
	 1. ดีกรี หรือ อันดับของกรณฑ์ ( index or degree ):
		 ความหมาย: เลขตัวเล็กที่อยู่กลางหน้าของเครื่องหมายกรณฑ์ ( หากเป็นดีกรี 2 จะไม่มีตัวเลข )
	 2. เครื่องหมายกรณฑ์ ( radical symbol ):
		 ความหมาย: เครื่องหมาย √
	 3. ตัวเลขในกรณฑ์ ( radicand ):
		 ความหมาย: ตัวเลขในเครื่องหมายกรณฑ์

	 เเสดงถึง:
		 การหาจำนวนที่คูณกันเอง ( ดีกรีของกรณฑ์ ) ครั้ง เเล้วผลลัพท์ได้ตัวเลขในกรณฑ์
