จำนวนจริง ( Real Numbers ):
	ความหมายของจำนวนจริง ( Meaning of Real Numbers  ):
		จำนวนจริง คือ จำนวนใดก็ได้ที่สามารถอยู่บนเส้นจำนวน 1 มิติ
			ประกอบด้วย: 
			 1.1. จำนวนตรรกยะ (Rational Numbers):
			     ความหมาย: จำนวนใดก็ได้ที่สามารถเขียนเป็นเศษส่วนได้
			 1.2. จำนวนเต็ม ( Integers ):
				 ความหมาย: จำนวนใดก็ได้ที่เมื่อคิดคำนวนเเล้ว จะไม่มีทศนิยม หรือ ไม่มีเศษส่วน
				 1.2.1. จำนวนเต็มบวก ( Positive Integers ):
					 ความหมาย: จำนวนเต็มที่มีค่ามากกว่า 0
				 1.2.2. จำนวนเต็มลบ ( Negative Integers ):
					 ความหมาย: จำนวนเต็มที่มีค่าน้อยกว่า 0
				 1.2.3. ศูนย์ ( Zero ):
					 ความหมาย: จำนวนเต็มที่มีค่าเป็น 0
			 1.3. จำนวนเต็มไม่ติดลบ ( Whole Numbers ):
				 ความหมาย: จำนวนเต็มบวกเเละศูนย์ ( มีค่ามากกว่า -1 เสมอ )
			 1.4. จำนวนธรรมชาติ ( Natural Numbers ):
				 ความหมาย: จำนวนเต็มบวก ( มีค่ามากกว่า 0 เสมอ )
			 1.5. ทศนิยมซ้ำ ( Repeating Decimal ):
				 ความหมาย: ทศนิยมที่เลขต่อไปไม่สิ้นสุด เเต่สามารถเขียนเป็นเศษส่วนได้
			 1.6. ทศนิยมรู้จบซ้ำ ( Terminating Decimal ):
				 ความหมาย: ทศนิยมที่เรารู้ทศนิยมตำเเหน่งสุดท้ายของจำนวนนั้น
				 
			 2.1. จำนวนอตรรกยะ ( Irrational Numbers ):
				 ความหมาย: จำนวนใดก็ได้ที่ไม่สามารถเขียนเป็นเศษส่วนได้
				 ตัวอย่าง: √5, √2, √3, 1.2358654...
				 2.1.1 ทศนิยมไม่รู้จบไม่ซ้ำ ( Non-terminating Decimal ):
					 ความหมาย: ทศนิยมซ้ำที่ไม่สามารถเขียนเป็นเศษส่วนได้

ระบบจำนวน ( Number Systems ):
	ความหมายของระบบจำนวน ( Meaning of Number Systems ):
		ระบบจำนวน คือ โครงสร้างทางคณิตศาสตร์ที่ใช้แสดงปริมาณและการคำนวณ
			 ประกอบด้วย:
			 1. ระบบจำนวนทางคณิตศาสตร์ ( Number Systems in Mathematic )
				 ประกอบด้วย:
				 1.1. จำนวนธรรมชาติ / จำนวนนับ:
					 คือ: จำนวนเต็มประกอบด้วยจำนวนเต็มบวก, ศูนย์ และจำนวนเต็มลบ
			  	   1.2. จำนวนตรรกยะ:
				  	   คือ: จำนวนที่เขียนในรูปเศษส่วนของจำนวนเต็มหรือทศนิยมซ้ำได้
				  1.3. จำนวนอตรรกยะ:
					 คือ: จำนวนที่ไม่สามารถเขียนเป็นเศษส่วนได้ เช่น ตรรกยะเข้าด้วยกัน
			      1.4. จำนวนเชิงซ้อน: 
				     คือ:  จำนวนที่อยู่ในรูป ( a+bi ) ซึ่งรวมถึงจำนวนจินตภาพด้วย


			 2. ระบบเลขฐานในคอมพิวเตอร์และดิจิทัล ( Numbers Systems in Mathematic )
				 ประกอบด้วย:
				 1.1. ฐานสอง (Binary): 
					 คือ: มีตัวเลข 2 ตัว คือ 0 และ 1 ใช้ส่งสัญญาณเปิด/ปิดในฮาร์ดแวร์
				 1.2. ฐานแปด (Octal):
					 คือ: มีตัวเลข 8 ตัว คือ 0 - 7
				 1.3. ฐานสิบ (Decimal):
					 คือ: ระบบที่มนุษย์ใช้ในชีวิตประจำวัน ประกอบด้วยตัวเลข (0 - 9)
				 1.4. ฐานสิบหก (Hexadecimal):
					 คือ: มีตัวเลขและตัวอักษร (16) ตัว คือ (0 - 9) และ (A - F) 
						 (แทนค่า (10 - 15)) นิยมใช้ระบุตำแหน่งหน่วยความจำ
